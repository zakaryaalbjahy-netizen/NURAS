# NURAS — Render/GitHub v1

NURAS institutional quality, performance, risk and accreditation platform.

Prepared for GitHub + Render deployment. No passwords, API keys, or secrets are included.

## Quick deployment
1. Upload this project to GitHub.
2. Create a Render Web Service from the repository.
3. Set `DATABASE_URL` privately in Render.
4. Run `schema.sql` against the PostgreSQL database.
